# HW2: генерация кода encoder-decoder Трансформером

Модель с нуля учится писать функцию `solve()` по текстовой задаче из `SlavaYus/tinysms_qa_12m`.
Итог: public pass@1 78.44% (753 из 960), тест из 1919 вопросов генерируется за 139.6 с на одной T4.

Ноутбук для проверки: `kaggle/inference.ipynb`; его выполненная итоговая версия с выводом лежит
в `kaggle/executed/inference_final_k12_2410.ipynb`. Код модели встроен в сам ноутбук, а для запуска на Kaggle
(GPU T4) ему нужны два публичных входа: датасет `lisich257/hw2-avg` (токенизатор, валидация, тест)
и output ноутбука `lisich257/continue` с весами `runs/continue_9x9/avg.pt`.

## Что где лежит

- `src/model.py`: encoder-decoder Трансформер (pre-LN, GELU, общие эмбеддинги) и генерация с KV-cache.
- `src/normalize.py`: перевод программы в короткое тело и обратно.
- `src/tokenizer.py`: BPE-токенизатор, числа отделяются от остального текста до BPE.
- `src/data.py`, `src/prepare.py`: валидация, скачивание и кодирование шардов.
- `src/batches.py`: батчи из примеров похожей длины с ограничением на число токенов.
- `src/train.py`: обучение (fp16, cosine по времени, DDP на нескольких GPU, сохранение и усреднение чекпойнтов).
- `src/average.py`: усреднение весов чекпойнтов и оценка на валидации.
- `src/execute.py`: исполнение программ в отдельном процессе и сравнение ответов с допуском 1e-6.
- `src/generate.py`: жадная генерация и файл сабмита.
- `src/vote.py`: несколько кандидатов на вопрос и голосование по результату исполнения.
- `kaggle/prepare.ipynb`, `kaggle/train.ipynb`, `kaggle/inference.ipynb`: ноутбуки для Kaggle; два последних
  собираются скриптами `kaggle/build_train.py` и `kaggle/build_inference.py`.
- `kaggle/executed/`: ноутбуки реальных запусков с выводом: дообучение итоговой модели, модель 12+12,
  сравнение вариантов инференса и итоговый инференс.
- `data/tokenizer.json`, `data/val.jsonl`: токенизатор и 2000 вопросов валидации из шарда 13.
- `explore.ipynb`: исследование данных и проверки по ходу работы.

## Как воспроизвести

1. `kaggle/prepare.ipynb` (CPU): скачать 60 шардов и закодировать их, output подключается как датасет `hw2-enc`.
2. `kaggle/train.ipynb` на 2×T4: `MODE = 'base'` (9+9 с нуля, 9 ч), затем `MODE = 'continue'`
   (дообучение ещё 7.5 ч). Остальные режимы повторяют эксперименты из отчёта.
3. `kaggle/inference.ipynb` на одной T4: ответы на тест и pass@1 на валидации.

Ноутбуки `prepare` и `train` клонируют код из приватного репозитория. Чтобы запустить их из этого архива,
положите папку с кодом в `/tmp/hse-nlp` и пропустите ячейку с клонированием.
